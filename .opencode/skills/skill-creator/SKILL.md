# Skill creator

Reglas para crear y modificar skills.

- Cada skill vive en `content/skills/<categoria>/<nombre>/SKILL.md`, y el nombre de la carpeta DEBE coincidir con el `name` del frontmatter.
- El frontmatter lleva `name` (minúsculas, palabras separadas por guiones) y `description`: qué hace la skill y cuándo usarla, con las palabras clave que disparan su uso.
- Escribe las reglas como items de una lista; no le pongas un encabezado propio a cada regla. Usa encabezados solo para cosas importantes o para dividir secciones.
- No agregues ejemplos, salvo que lo explicado sea realmente complejo o aporte contexto sustancial. SIEMPRE consulta al usuario antes de poner un ejemplo.
- Escribe en español.
- Agrega solo las reglas necesarias. No sobre-ingenierices ni anticipes reglas que todavía no hacen falta.
